# DJ Kena Official Website

The official website of DJ Kena — a professional DJ and entertainer bringing music, energy, and unforgettable experiences to the scene.

## Features
- Responsive layout for desktop and mobile
- About, mixtapes, events, gallery and booking sections
- DJ Kena black, gold and subtle purple visual identity
- Lightweight HTML, CSS and JavaScript

## Run locally
Open `index.html` in your browser. No build tools or dependencies are required.

## Before publishing
1. Replace the YouTube and social links with DJ Kena's actual profiles.
2. Update `bookings@example.com` in `index.html` with the booking email.
3. Add real performance photos to the gallery.
4. Add links to released mixtapes.

## Deploy with GitHub Pages
Push this repository to GitHub, then open **Settings → Pages**. Choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
